# Fontes base da biblioteca do Otto

Os 18 arquivos desta pasta vieram de `poc/fontes/` e são semeados na biblioteca de fontes
(tabela `fontes_da_biblioteca` e armazenamento) pelo comando `pnpm --filter @otto/api biblioteca:semear`,
que o serviço `semear` do compose roda a cada subida. `indice.json` diz a família e o peso de cada arquivo.

O nome PostScript de cada fonte é lido do próprio arquivo na semeadura.

**Licença.** O `README` da POC declara todas como SIL Open Font License. Isso ainda não foi conferido
arquivo por arquivo: é pendência do jurídico antes do primeiro pagante (`CLAUDE.md`).
